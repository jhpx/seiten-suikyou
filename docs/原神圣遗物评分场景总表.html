列定义与生成方式
场景：分支名（自定义规则命中特判时）或 基础/默认表/通用兜底（未命中任何特判）。角色名前缀（钟离-武神 → 武神）已剥掉，旁边就是角色列。
场景名带括号后缀的（如 高命（6命）、高配（充能40））：artis.js 里的标题是写死的字符串，命座或武器不同时返回的是同一个名字、不同权重，直接列出来会像重复行。后缀是本表加的区分标记——能按命座切开就标命座区间，切不开就标那套权重与众不同的读数。
触发条件：由 artis.js 的 if 树符号执行还原，「或」表示多条等价路径。兜底行指所有特判都没命中时走的路径，条件是那些特判条件的反面。权重来源：分支内权重=artis.js 显式给出；默认表原值=兜底时直接取 usefulAttr；内置基准=artis.js 手写了一整套兜底权重、不查默认表。
生成器：tools/gen_artis_table.ts（npm run gen:artis-table）。静态解析 if 树还原条件文字，动态执行规则函数实测权重，两边按（场景名, 权重）配对校验；本页由该脚本生成，请勿手改。
