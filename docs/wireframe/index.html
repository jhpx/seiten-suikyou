这份稿子的用法

只回答三个问题：长什么样（区块、层级、尺寸、颜色）、怎么点（入口、出口、浮层、状态流转）、什么状态（加载、失败、空、成功）。结构标签、模块划分、接口、数据字段与文件位置都不在本稿范围内。通用视觉规格见 设计规格，页面与状态总表见 交付清单。
