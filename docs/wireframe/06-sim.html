版式规范

  • 顺序固定：返回栏 → 角色头 → 属性对照 → 装备清单 → 伤害对比。
  • 装备卡改成纵向单列并拉满栏宽，图标缩小；不要沿用首页那种 3 列小卡。
  • 伤害对比跨整卡宽，放在两栏内容之下；列宽不随行内容变化。
  • 旧值与新值用同一字号，靠颜色和箭头区分，不用加粗制造假重点。

状态

没有选中角色时整页只给一句「无数据」。伤害结果算不出来时，表格位置给一行说明，而不是留一张空表。所有改动在确认前都只是假设，随时可整体还原。
